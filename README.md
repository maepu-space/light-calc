# 光と電気の計算ツール

植物を育てるLEDについて、次の値をブラウザだけで計算するツールです。

- 1日の光の量（DLI）
- 距離と反射を考えた、面に届く光の割合
- 必要なLED出力と消費電力
- 電気代（1日・1か月・栽培1回分）
- 温室内の温度上昇（壁の材質と換気量から）

**公開ページ：** https://maepu-space.github.io/light-calc/

## 使い方

ページを開き、目標PPFD・点灯時間・栽培面積・LEDまでの距離・LED効率・電気単価を入れます。
「例」のボタンで代表的な条件を呼び出せます。

## 前提と注意

- 設計用の目安です。実際の光量は光量子センサーで確認してください。
- LEDは真下が最も明るい一般的な配光とし、反射光はすべて面に届くもの（最良の場合）として計算しています。
- 温度上昇は、消費電力がすべて熱になり、温度が落ち着いた状態の値です。葉の蒸散による冷却は含みません。
- 電気単価の初期値31円/kWhは目安単価です。契約の単価に合わせてください。

## 計算式

| 項目 | 式 |
|---|---|
| DLI（mol/m²/日） | PPFD × 点灯時間 × 3600 ÷ 1,000,000 |
| 面に届く割合 | r² ÷ (r² ＋ 距離²) ＋ 届かなかった光 × 反射率（r：面積と同じ面積の円の半径） |
| 必要なLED出力（µmol/s） | PPFD × 面積(m²) ÷ 面に届く割合 |
| 消費電力（W） | 必要なLED出力 ÷ LED効率(µmol/J) |
| 電気代 | 消費電力 × 点灯時間 ÷ 1000 × 電気単価 |
| 温度上昇（℃） | 消費電力 ÷（壁の熱の逃げやすさ × 壁の面積 ＋ 1200 × 換気量(m³/s)） |
